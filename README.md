Objectif : modéliser en 3D le plateau de Loess ansi que les differentes couches stratigraphiques. 

A partir des données topographique, le groupe A modélise le réseau hydrographique du plateau.
Grâce au informations de trois forages, le groupe C réalise un modèle 3D des couches géologiques avec pour chaqes couches des informations sur les propriétés des roches.
Enfin, les groupe B réalise un modèle d'érosion basé sur les données du modèle 3D et du réseau hydrographique pour simuler plusieurs sénario d'érosion du plateau.
